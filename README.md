# ChatWeb — 实验版

**版本 0.1.0-experimental.1 · Windows · 本机使用**

用 Codex 的 Plus / Pro 额度跑点重活，那个额度条掉得比想象中快。几个稍大的改动下来，
就得开始掰着指头算着用，或者眼睁睁看它变灰 —— 而手边那份 ChatGPT 网页版订阅，
平时不过就是聊聊天。

ChatWeb 想把这两件事接上：让 DSH 这类本地 Agent 把「想」的部分交给 ChatGPT 网页版，
「做」的部分仍然在你自己的电脑上执行。已经付过钱的额度，别让它闲着。

**先把丑话说在前面：**

- 这是个折腾人的实验品，不是装完就能用的成品。要装 Node、要配本地认证、要一个能正常登录的浏览器。
- 它**不是官方接口**，靠自动化你已登录的网页会话来工作。这可能受平台使用条款限制，
  也可能因为网页改版某天突然失效。用之前请自己判断风险。
- **请不要拿它去绕额度、绕风控或批量刷**。它只是把你本来会手动做的那点事自动化了一点点。
- 目前不支持图片，也不宣称支持 Codex、GPT-6 或 GPT-6 Pro。它不是万能钥匙。
- 服务只监听本机，**不要开放到局域网或公网**。

如果你也经历过「额度还剩 3%，活还没干完」的下午，这个项目大概就是为你写的。

## 项目做什么、不做什么

- 使用你自己正常登录的专用浏览器，通过网页 Chat 路线完成现有 DSH 任务。
- 在电脑本机运行两个小服务：DSH → 127.0.0.1:1457 → 127.0.0.1:1456 → 专用浏览器。
- 不提供账号、登录凭据或额外模型额度；不会自动切换到消耗 Work／Codex 额度的官方授权路线。
- **本版不宣称支持 Codex、GPT-6 或 GPT-6 Pro。** 后两者仍未启用，不能靠改名字冒充接通。
- 不支持图片输入；不承诺长期稳定、无限额度、特定响应速度或官方支持。

## 安装：先准备工具，再装到新目录

需要 Windows、PowerShell 7（pwsh）、Git、Node.js ≥22.15 和 npm。
实际聊天还需要 Chrome 或兼容浏览器、DSH，以及你能正常使用的网页账号。
安装步骤不会提供或代替这些账号权限。

**不要覆盖现有生产目录。** 请把源码包解压到一个新目录，再在该目录执行：

```powershell
pwsh -NoProfile -File ./scripts/accept-windows.ps1 -Install
```

该命令会核对源码和许可信息、从公共npm源安装锁定依赖、重建适配器并跑离线检查。
它不登录账号、不启动真实服务或浏览器、不注册开机任务，也不提交真实模型任务。
这里是提供给安装者的核对步骤，不是要求维护者重做已经完成的验收。

若取得的是Git源码目录，先导出到尚不存在的目录，再执行上面的命令：

```powershell
node scripts/export-source.mjs ../chatweb-source-review
Set-Location ../chatweb-source-review
```

使用已有公共包缓存的离线装法、失败后的处理方式，见 [详细安装说明](INSTALL.zh-CN.md)。
安装失败时保留现场，换新目录处理；不要删除用户数据或关闭安全检查来强行启动。

这份源码保留两层本地服务认证。**缺少对应配置时，启动会拒绝，而不是自动生成密钥或跳过验证。**
新增认证方案本轮暂不部署；已有使用环境保持原样。本轮仅整理发行源码。
将来在另一个环境启用本源码前，请先阅读 [安全说明](SECURITY.md)，由该环境的使用者明确配置本地凭据。
不要把网页登录Cookie、真实服务密钥写入脚本、仓库或问题反馈。

以下示例只适用于已明确完成所需本地配置的环境。
在你希望DSH工作的目录中执行：

```powershell
& '<ChatWeb源码目录>\run.ps1' '你的任务'
```

这会按需启动本项目服务，并通过DSH执行任务，**可能消耗网页账号额度**。
它不是安装验收命令。本地凭据缺失或错配会停止，不自动改账号、换渠道或重试。
停止前先确认没有任务进行；其它启动／停止选项见 [详细安装说明](INSTALL.zh-CN.md)。
只给工具必要的文件和执行权限，先检查任务范围，不要把私人资料无差别交给模型。

## 已知故障和限制

- 网页更新、模型菜单变化或账号权限变化可能使桥接失效；此前成功不保证以后成功。
- 登录过期、验证码、风控提示或额度不足时会失败。请按网页正常流程处理，不绕过验证或限制。
- 网页提交后丢失响应时，可能已经消耗额度；状态不确定的请求不自动重放，避免重复提交。

- 健康接口正常只表示服务有响应，不代表任务一定成功。额度、耗时和用量估算不构成账单保证。

## 图片输入（本地扩展）

本节是本地扩展记录，接在前面「不支持图片输入」的既有口径之后：对外口径不变，
以下只描述本轮在本地打通并验证的图片输入链路及其边界。
链路：DSH（本地 harness）→ `127.0.0.1:1457`（dsh-chat-tool-bridge，OpenAI 兼容 `/v1/chat/completions`）
→ `127.0.0.1:1456`（pi-chatgpt-web-adapter）→ 受管 Chrome → `chatgpt.com`。

- DSH 在 `messages[].content` 用 OpenAI content 数组携带图片；桥只接受 base64 data-URL，
  解码校验后写入临时文件，由适配器在 chatgpt.com 页面内完成三步上传
  （`POST /backend-api/files` → `PUT` Azure SAS → `POST …/uploaded`），
  并随消息以 `multimodal_text` 提交。
- 转写文本中每张图片出现 `[图片 #N]` 标记；同一请求内按 sha256 去重，重复图片复用同一编号。
- http/https 形式的图片 URL 一律拒绝（`400 invalid_request`）：桥不会代替 harness 抓取远程内容。

### 请求示例

写法一（OpenAI `image_url` 部件）：

```json
{
  "model": "gpt-5-6-thinking",
  "messages": [
    {
      "role": "user",
      "content": [
        { "type": "text", "text": "图里第一行字是什么" },
        { "type": "image_url", "image_url": { "url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg==" } }
      ]
    }
  ]
}
```

写法二（responses 风格 `input_image` 部件，桥同样接受）：

```json
{
  "model": "gpt-5-6",
  "messages": [
    {
      "role": "user",
      "content": [
        { "type": "input_image", "image_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg==" },
        { "type": "text", "text": "图里第一行字是什么" }
      ]
    }
  ]
}
```

### 限制

| 限制 | 取值 | 超限表现 |
| --- | --- | --- |
| 单请求图片数 | ≤ 8 张（sha256 去重后计数） | `400 invalid_request` |
| 单张图片大小 | ≤ 20 MiB | `400 invalid_request` |
| 请求体大小 | ≤ 32 MiB | `413`（Request too large） |
| 图片来源 | 仅 `data:image/(png\|jpeg\|webp\|gif);base64,…`；http/https 一律拒绝 | `400 invalid_request` |

### 模型开关

- `dsh-chat-tools.patch.yml`：`gpt-5-6-thinking` 与 `gpt-5-6` 均声明 `input: [text, image]`，
  DSH 侧才允许向这两个模型发送图片。
- `web-model-metadata.json`：受审模型可加 `"image_input": true`，`model-routes.mjs` 据此生成
  `input: ['text', 'image']` 的 DSH overlay；该值必须是布尔 `true`，其它取值拒绝加载。

### 临时文件生命周期与清理

- 写入位置：`<仓库目录>/.runtime/uploads/pcw-img-<uuid>.png|jpg|webp|gif`
  （可用环境变量 `PCW_UPLOAD_DIR` 覆盖目录）。
- 上游请求完成后即删；崩溃残留由启动清扫兜底：只删 `pcw-img-` 前缀且超过 24 小时的文件。
- `.runtime/uploads` 不是留存记录，不要手工往里放文件，也不要依赖它跨会话保存图片。
